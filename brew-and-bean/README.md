# Brew & Bean — Premium Café Website

Fictional concept/demo website created for the Web Matrix portfolio.

## Files
- `index.html` — semantic page structure and editable café content
- `style.css` — responsive editorial design
- `script.js` — menu data, mobile navigation, scroll header and reveal animations

## Easy edits
Change the café name/tagline, address, hours, contact details, social links and image URLs directly in `index.html`.

Menu names and prices are centralized in `script.js` inside `menuData`.

## Notes
The site uses remote Unsplash image URLs for demo photography and Google Fonts for typography. Replace these with licensed/local assets before using the design for a real client.
All business details are placeholders. The site contains no fabricated testimonials, reviews, awards, revenue figures or business-result claims.
